Pedro Vasconcelos // Sobre Mim

  • Sou Pedro Vasconcelos, estudante de Informática e um grande entusiasta do universo da tecnologia. Desde cedo, o desejo de compreender a lógica e o funcionamento por trás das ferramentas digitais despertou a minha curiosidade, impulsionando-me a entrar no mundo da programação e a descobrir a satisfação de transformar ideias em código e soluções práticas.

  • Atualmente, o meu foco principal está no desenvolvimento web, onde me dedico a criar páginas e aplicações funcionais, dinâmicas e visualmente apelativas. Sou um entusiasta da prática constante: crio projetos a partir do zero, testo novas ferramentas e experimento com diferentes linguagens e frameworks, procurando sempre aperfeiçoar a arquitetura das aplicações e a experiência final do usuário.

  • Acredito firmemente que o verdadeiro crescimento técnico e pessoal acontece na resolução diária de problemas. Encaro cada erro como um diagnóstico valioso para aprender mais e cada desafio superado como um degrau essencial no meu percurso. O meu grande objetivo é consolidar continuamente estes conhecimentos e construir uma carreira sólida, inovadora e de sucesso como desenvolvedor profissional.

M i n h a s S k i l l s

  • JavaScript

    JavaScript é a linguagem que dá vida às páginas, permitindo interações, animações, validações e comportamento dinâmico em tempo real.

  • HTML

    HTML é a base da web, responsável por estruturar textos, imagens, links, formulários e todos os elementos que compõem uma página.

  • CSS

    CSS é usado para deixar a interface visualmente atraente, controlando cores, espaçamentos, responsividade, tipografia e layout da página.

  • Node.js

    Node.js permite executar JavaScript no servidor, criando aplicações rápidas e escaláveis para APIs, backend e serviços web.

  • Git

    Git é o sistema de versionamento que registra alterações no código, facilita a organização do trabalho e ajuda a manter o projeto seguro e rastreável.

  • GitHub

    GitHub é a plataforma de hospedagem de repositórios que permite colaborar em equipe, compartilhar código e gerenciar projetos de forma organizada.

  • C#

    C# é uma linguagem poderosa usada para desenvolver aplicações robustas, com foco em organização, segurança e escalabilidade em projetos maiores.

  • Figma

    Figma é usado para prototipar interfaces, criar layouts e validar a experiência visual antes da implementação em código.

  • UX/UI

    UX/UI concentra-se na jornada do usuário e na criação de interfaces intuitivas, agradáveis e funcionais para uma melhor experiência.

  • SQL

    SQL permite armazenar, consultar e manipular dados em bancos relacionais, sendo essencial para aplicações que dependem de informações estruturadas.

  • VS Code

    VS Code é o editor principal para escrever código com produtividade, extensões, depuração e suporte a diversas linguagens e ferramentas.

  • Visual Studio

    Visual Studio é um ambiente completo de desenvolvimento que oferece ferramentas poderosas para escrever, testar e depurar aplicações com eficiência.

  • API

    API permite que sistemas diferentes se comuniquem entre si, trocando informações de forma segura e padronizada para criar integrações úteis.
